# Xtream Codes

De meeste Xtream Codes-streamlinks hebben deze opbouw:

~~~text
http(s)://{hostname}:{port}/{username}/{password}/{channelID}
~~~

De poort is vaak **25461**.

Om na te gaan of een host een Xtream Codes-server is, kunnen de hostnaam, poort, gebruikersnaam en het wachtwoord in deze API-URL worden verwerkt:

~~~text
http(s)://{hostname}:{port}/panel_api.php?username={username}&password={password}
~~~

Als de server een antwoord terugstuurt, is dit een aanwijzing dat het om een Xtream Codes-server gaat.

**Belangrijk:** dergelijke adressen bevatten vaak persoonlijke toegangsgegevens. Publiceer ze niet en gebruik ze niet om de toegang van derden zonder toestemming te benaderen.
